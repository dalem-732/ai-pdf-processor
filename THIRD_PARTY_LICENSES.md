Проект распространяется по [MIT](LICENSE). Ниже лицензии сторонних пакетов,
чтобы совместимость была подтверждена, а не предполагалась: MIT допускает
коммерческое использование и распространение, и все зависимости этому не
противоречат.

## Данные и модели

- **Тестовый PDF** генерируется скриптом `scripts/make_sample_pdf.py` и
  содержит только вымышленные данные. Реальные файлы с ЕИС в репозиторий не
  включаются: у них другой правовой режим и в них встречаются персональные
  данные.
- **Шрифты** для генерации PDF не распространяются с проектом: скрипт использует
  шрифт, уже установленный в системе (DejaVu Sans - Bitstream Vera License,
  Liberation Sans - SIL Open Font License).
- **Модели LLM** не входят в поставку. Использование OpenAI и Anthropic
  регулируется их пользовательскими соглашениями, локальные модели в Ollama -
  лицензиями конкретных весов (например, Qwen2.5 - Apache-2.0, Llama 3.1 -
  Llama 3.1 Community License). Перед отправкой закупочной документации во
  внешний API проверьте, допускает ли это ваш регламент обработки данных;
  провайдер `ollama` существует именно для случая, когда не допускает.
